# Foaie de parcurs Android

Versiune de lucru pentru Android.

Funcții incluse:
- Plecare: oră + localizare, kilometraj preluat din ultima sosire
- Sosire: oră + localizare + cameră pentru odometru + kilometraj
- Alimentare: fotografie bon + litri + preț/litru + valoare
- Cheltuială auto: fotografie document + tip + valoare
- Decont personal
- Istoric local
- Backup/restaurare
- Build automat APK prin GitHub Actions

Etapele următoare: OCR pentru bonuri/facturi și generarea PDF-urilor după modelul agreat.
